# Global Ads Analytics Dashboard

## Overview

This project focuses on analyzing global advertising performance across different regions, platforms, and campaigns. The main idea was to understand how ads are performing and where the marketing budget is actually working.

The dashboard was built to help quickly see what’s working and what’s not without digging through raw data.

## What I tried to solve

* Which regions are generating the best results?
* Which ad platforms are performing better?
* How does spending relate to conversions and clicks?
* Where is the budget being wasted?

## Tools used

* Power BI
* Excel
* Python (basic cleaning & preparation)
* DAX (for calculations)

## Dashboard features

* Region-wise performance breakdown
* Campaign comparison view
* Spend vs return analysis
* Clicks, impressions, and conversion tracking
* KPI summary cards

## Key takeaways

* Some regions perform consistently better even with lower spend
* High impressions don’t always lead to conversions
* A few campaigns are driving most of the results
* Budget allocation could be improved based on performance trends
